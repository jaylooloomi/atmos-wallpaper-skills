# F5 初始畫面閃動修正 0.3.3

日期：2026-11-04。

使用者提供的 GIF 顯示：F5 後先出現凍結原型的綠色佔位場景與舊面板，接著逐步載入主題、真實圖片、字型及新版控制列，造成多次畫面跳動。

## 修正

- 初始 HTML 即包含顯示閘門與極小的行內載入樣式，不能在主程式啟動前露出舊版頁面。內容使用 visibility 隱藏，保留真實排版尺寸供座標與畫布測量，不使用 display:none。
- 沿用既有 snapshot 驗證、圖片 SHA-256／解碼流程；在所有 UI 模組完成、必要樣式有實際規則、字型就緒、場景縮圖解碼完成後，重新同步幾何並等待版面 frame，再一起顯示已套用設定的頁面。只對初次載入生效，一般更新保留上一有效畫面。
- 核心圖片／樣式失敗或就緒等待超時時維持遮蔽，顯示可重新載入的提示；可選縮圖失敗不永久封鎖已驗證的主要場景。顯示閘門先解除，後續才走正常 renderer ack；不因載入提示而送成功 ack。
- 載入邏輯嵌入既有 bridge-client.js，不新增舊服務必須知道的靜態路由。未改交易、使用者設定或凍結 prototype。
