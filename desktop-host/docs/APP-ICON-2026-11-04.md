# Atmos 應用程式圖示 0.3.8

日期：2026-11-04。

以目前的動態桌布、程式天氣與時間元件為設計重點：山形 A 代表 Atmos 與風景，流動地平線代表動態環境，暖金色日光時鐘代表日夜與時間。深藍綠圓角底、薄荷綠主形及金色重點在淺／深背景都能辨識；避免把多個細小功能符號擠進 16px 圖示。

## 資產與製作方式

- 向量來源：[atmos.svg](../icons/atmos.svg)。直接以 SVG 幾何、漸層與透明圓角製作，沒有使用 AI 點陣圖生成或修改使用者提供的圖片。
- 512px 透明 PNG：[atmos.png](../icons/atmos.png)。
- Windows ICO：[icon.ico](../icons/icon.ico)，含 16、20、24、32、40、48、64、128、256px 九個獨立尺寸。
- 尺寸／底色預覽：[preview.png](../icons/preview.png)，展示淺底／深底的 16–64px。

`node scripts/build-icons.mjs` 使用獨立 Chromium CLI 將向量渲染為透明 master，再以 Pillow 執行尺寸與 ICO 格式匯出；不是使用者瀏覽器／桌面 UI 自動化。建置端需要 Chromium、Python／Pillow，可透過 ATMOS_TEST_CHROME、ATMOS_PYTHON 指定。顏色與抗鋸齒細節可能隨渲染器版本而異，不保證跨工具版本逐位元組相同；一般使用者的安裝版不需要這些開發工具。

## 套用

應用程式資源使用新版多尺寸 ICO。系統匣改為取用 Tauri 的應用程式圖示，移除原本程式碼建立的純色青色方塊；托盤選單與桌布生命週期不變。NSIS 安裝及解除安裝圖示也指定相同 ICO。不更動管理頁布局、設定結構或 Agent 介面。
