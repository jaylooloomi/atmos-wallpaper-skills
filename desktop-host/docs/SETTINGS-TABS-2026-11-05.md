# 方案 A：設定分類分頁（0.7.4）

控制面板使用「桌面元件／螢幕保護／外觀字型」三個分頁，沿用現有主題配色及左側等比預覽，不新增另一套設定資料。

- 桌面元件：七個元件的顯示開關、各自內容設定；天氣資料來源、更新狀態與定位集中在天氣卡片。桌布與系統設定集中於可展開區。
- 螢幕保護：保留已連接螢幕選擇、現有設定及 Windows 安裝／設定按鈕；提供日期時間與日曆摘要及返回元件入口。不把草稿開關誤當成 Windows 已啟用螢幕保護的證明。
- 外觀字型：主題、場景效果、配置與各元件的字型、顏色及位置。

切換分頁只改顯示，不儲存或重新載入。既有輸入節點與事件處理器保留，避免切頁遺失草稿。底部「套用變更」轉交原本的版本檢查與套用流程；系統設定仍依各區既有規則儲存。支援五種介面語言、鍵盤方向鍵／Home／End 及分頁 ARIA 關聯。
