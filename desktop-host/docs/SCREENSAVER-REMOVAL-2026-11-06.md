# 螢幕保護功能移除（0.7.16）

依使用者要求移除螢幕保護，動態桌布、資訊元件、音訊、啟動與省電模式維持原功能。

- 管理頁刪除螢幕保護分頁、摘要與設定入口，只保留桌面元件／外觀字型；兩分頁鍵盤導覽與草稿保留。
- 不再載入或封裝 screensaver client／service；準備 frontend 時清掉已退休的舊生成檔。
- 移除可建立螢幕保護視窗的 Rust 模組。`.scr`／`/s`／`/c`／`/p` 與啟用／設定 CLI 回覆 `SCREENSAVER_REMOVED`，不啟動畫面。Node 原生執行入口亦拒絕 screensaver presentation。
- 啟用 HTTP 端點退役為 410，無法透過注入舊 service 啟用；Agent help 與 active host schemas 不再提供此命名空間。低層舊角色／隔離讀取測試保留相容性，並非產品啟用入口。
- 安裝不再複製 `Atmos.scr`。升級／解除安裝只針對該安裝路徑的舊事件與選取清理：精確命中自己的 `SCRNSAVE.EXE` 才還原先前選取或清除；其他螢幕保護選擇不動。不變更 Windows active／timeout／驗證或寬限設定。
- 保留精簡的 legacy 清理模組、舊版 stop／unregister 相容別名，讓已發行的解除安裝程式仍可安全運作。清理只可刪固定的 `Atmos.scr` 與五個退休 payload 檔案；先拒絕重解析點／非一般檔案，不刪設定、素材或歷史。舊 screensaver-settings 資料保留但不再使用。

## 自動驗證

更新根目錄 AGENTS.md 與 gate 契約為兩個有效分頁，加入「不得出現退休分頁／控制／script」條件。仍保留 12 視窗、336 元件風格、1,008 資訊範本、336 省電狀態、四風格對比、寬度對齊、工具列及重疊負控制。並非將已移除功能默默略過。

Rust 51 項通過，包括原本精確歸屬還原的測試及固定清理路徑範圍。完整 verify 通過：產品 468 pass／3 skip、核心 41 pass／2 skip；5 個 skip 仍為既有平台能力情境。

封裝前第二次完整 gate 亦通過；兩分頁、共同元件清單、四風格對比、寬度與吸頂等檢查維持通過。0.7.16 已更新安裝：升級前 Windows 確實選用 Atmos，升級後已不再選用；舊 Atmos.scr 與五個退休 payload 檔案皆不存在。10 份既有設定逐位元組保留，啟動與資訊省電模式沿用；Windows 的 active／timeout／驗證／寬限值不變，非 Atmos 選取保護檢查通過。新啟用 CLI 回覆移除錯誤，schema 不含退休功能；實際 HTTP 端點回覆 410、退休 client 回覆 404。[安裝與實機清理結果](../evidence/screensaver-removal-upgrade-2026-11-06.json)。原始設定與登錄快照只留本機。僅使用隔離合成 Chromium、CLI 與登錄查詢，不操作使用者 UI，不啟動真正螢幕保護、不鎖屏或代為認證。
