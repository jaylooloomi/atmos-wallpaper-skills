# 語言選單移至上方操作列（0.7.25）

依使用者兩張截圖，將既有 localeControl／appLocale 節點從預覽解析度旁移至上方操作列，位於桌布快捷操作（包含重新確認狀態）之後、資訊省電開關之前。取消 previewLanguagePanel 容器，不留下空框；預覽解析度保留原欄位置。

移動原節點，不重建選項或 onchange，因此保留語言選擇與原草稿／套用行為。兼顧初始化先後順序，桌布快捷操作建立後仍將語言置於其後，DOM 與顯示順序一致。調整 readonly 的控制列例外，語言欄仍會在載入／交易中鎖定，不因移入操作列而繞過原流程。

樣式沿用控制列配色、8px 圓角與至少 44px 控制高度。寬螢幕單列並對齊中心，窄螢幕整組自然換行。單元測試覆蓋位置、原容器不存在及鎖定行為；12 尺寸矩陣新增位置、寬高、按鈕重疊及單列條件，對比檢查納入語言標籤與選單。原有三分頁、元件、資訊範本、省電與負控制保留。
