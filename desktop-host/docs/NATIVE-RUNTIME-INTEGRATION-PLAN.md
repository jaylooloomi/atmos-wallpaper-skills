# Windows 0.7.36 Rust 宿主與驗證摘要

0.7.36 在整合分支將 Rust 設為 Windows x64 正式建置預設。Tauri 宿主以同一執行檔啟動 Rust loopback HTTP worker，Windows Job 負責回收程序。設定交易、Agent、顯示配置、音訊、排程、素材庫與資料來源由 Rust 處理。舊設定與日曆資料有相容性驗證。

安裝內容包含 WebView2 使用的前端資產、凍結素材和內嵌 Python／Pillow 圖片解碼器。安裝內容已移除 Node 執行檔、npm 模組與舊 JS 後端，升級會清理已知的舊 Node 目錄。開發預覽、前端建置、封裝工具及 JS／Rust 比對仍使用 Node。

## 已驗證

| 範圍 | 結果 |
| --- | --- |
| 正式建置來源 `a27b6bb` | 完整 verify 耗時 151.8 秒，產品與核心共 594 項通過、5 項依既有條件略過、0 失敗。12 種版面、原有情境及重疊負控制通過。 |
| 原生自動驗證 `a27b6bb` | 耗時 145.6 秒。89 項 Rust 測試、17 項 HTTP 邊界、21 項 JS／Rust 差異與 16 項宿主整合全過。隱藏 WebView2 的管理頁及桌布 renderer 均實際回報 ACK，Windows 掛載另列於實機結果。 |
| 隔離安裝目錄 `a27b6bb` | 暫存 payload 共 775 個檔案，無 Node、npm 模組或舊 JS 後端。候選執行檔在空 PATH 下通過自檢，能移除舊 Node 目錄並拒絕損毀 payload。素材庫 8 項通過，涵蓋搬移、重送、設定與備份保留、離線重連、Windows ACL 拒絕與有 session 驗證的 HTTP 讀取。 |
| 後續 UI `148fb3a`、`6558131` | 390px 與 1280px 快速驗證通過。天氣特效兩列各五個，四欄注入在兩種寬度均被拒絕。四種主題及高對比原生箭頭通過，既有工具列陰影斷言在高對比模式仍會失敗。 |
| 較早的 Rust 候選版 | 使用者在 Windows 確認桌布套用、系統匣、退出還原及實際重新登入自動套用。隔離網路測試曾從 Open-Meteo、GitHub、Yahoo 和公開 RSS 取得新資料。 |
| 較早的 0.7.36 NSIS 原地升級 | 從 0.7.35 升級後，首次啟動前核對的 5,767 個設定與素材檔案均保持原值，登入啟動登錄值保留。於同一 Windows 工作階段直接執行登錄命令，桌布成功掛載並回報 ACK，三次程序樹採樣無 Node，退出後桌布恢復。 |

前四列使用隔離環境，未執行 NSIS。後兩列對應先前的候選版或安裝產物。

## 待驗證

- 從含後續 UI 的最終交付提交重跑完整 verify、原生 gate 和安裝自檢，再製作安裝檔並記錄對應雜湊。
- 在隔離 Windows 帳戶或 VM 驗證全新安裝、升級後真正重新登入、掛載與退出還原。登入入口直跑和較早候選版的重新登入已有各自的驗收紀錄。
- 0.7.35 與 0.7.36 的安裝大小、啟動時間、GPU、耗電與長時間耗用仍待同環境對照實測。

原始報告、測試資料與安裝檔留在本機。命令與操作界線見 [開發指南](../../DEVELOPMENT.md)。
