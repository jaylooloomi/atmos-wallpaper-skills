# 預覽說明卡片自然高度 0.3.6

日期：2026-11-04。

使用者指出預覽下方說明卡片有大片不必要的空白。原因是舊版底部對齊邏輯把右側面板需要的最小高度加到左側說明卡片的 min-height，使卡片成為填補空間的工具；這與「預覽比例不隨右側變長」的說明不一致。

## 修正

說明卡片改成依文字內容自然決定高度，不設定補償用 min-height。右側面板的高度獨立取自然預覽區下緣與右側必要高度的較大值；需要較高面板時不再反向撐高左側卡片。保留預覽目標比例、右側元件最小可用高度、雙欄上緣對齊及小螢幕堆疊方式。

ResizeObserver 改觀察說明卡片、預覽 viewport 及預覽工具列，不再觀察會被右側高度拉長的整個左欄，減少左右高度互相觸發。文字及其位置未改，也不調整使用者儲存的畫面設定。

## 驗證

- 新增兩項回歸測試：直接執行現有 align 函式，在右側必要高度較短／較長時確認說明卡片不被賦予 min-height；切換窄螢幕時清除舊高度。
- 隔離 Chromium CLI 在 320×844 natural、390×844 neon、1280×900 natural、1876×1080 natural 皆通過。以相同文字／寬度、移除強制高度的測量副本比較，說明卡片高度等於自然文字高度。
- 測試切換右側到天氣元件後，說明卡片高度不變；實際預覽寬高比仍等於目標 1920／1080。桌面說明卡片約 111px／158px，窄螢幕隨換行增加，不設定不合理的統一固定高度。
- 同時檢查控制面板頂端對齊、欄位寬度、場景順序、橫向溢出與浮動工具列。診斷保留 ResizeObserver 延後通知數，不掩蓋其他未處理例外；單次通知與持續重複警告分開，幾何穩定性另行驗證。
