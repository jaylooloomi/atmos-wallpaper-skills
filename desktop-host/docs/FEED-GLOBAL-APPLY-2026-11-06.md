# 資訊元件共用套用 — 開發中（未發版）

## 原因與修正

使用者在元件選取區開啟 GitHub 後按上方套用，獨立 daily-feeds 設定未被提交；管理頁也沒有依該草稿預覽。修正前讀取實際宿主：GitHub、Yahoo、RSS 均關閉，已有快取並非未抓到資料，專注模式為 normal。

開關、字級、位置與 RSS 欄位現在先在本頁預覽；上方套用保存資訊元件草稿，再提交外觀草稿，上方取消亦會重新讀取資訊元件設定。僅資訊元件變更不製造外觀交易。版本衝突、無效 RSS、儲存失敗或不匹配的成功回覆均不清掉草稿；處理中鎖定控制項與重複提交。開啟 RSS 必須填有效公開 HTTPS 網址。

兩個 namespace 仍為各自交易，並非跨 namespace 原子提交。資訊元件成功、外觀失敗時，資訊元件已保存，外觀保留既有復原／重試流程。元件拖曳仍依原本流程立即保存。
