## 新版行為

- 三分頁的設定區塊預設收合、同分頁互斥展開，再點同一張可收起；桌面元件保留選取卡片，下方同時只顯示一個設定區。直接搬移原控制項，未儲存內容與事件處理保留。
- 舊「元件管理」標題、提示與重複導覽移出可見介面；隱藏的相容綁定保留。元件設定的可見性由新版選取狀態控制，舊 inspector 的收合狀態不再把番茄鐘內容藏起來。
- 卡片標題上移、去除首項多餘留白；天氣標題保持在資料來源設定上方；收合標題保留 44px 點擊高度。
- 「模式」「編輯目標」與錨定螢幕標籤／選單同列；上方「重整／語言」間加入一致分隔線。
- 「螢幕與桌布放置」「Windows 啟動」依序排在系統分頁最上面。
- 系統資訊加入清楚的上傳／下載文字與雙區塊 SVG 流動箭頭。只有有效正流量才啟動；省電、減少動態、隱藏或原生暫停時停止，資訊仍更新。保留動畫節點，資料取樣不重建箭頭。正常／減少動態及 224／280／360px fixture 驗證原 178px 高度無裁切，沒有增加卡片面積。
- Node 開發預覽支援獨立的固定前端快照，避免重建 dist 時干擾預覽；明確覆寫拒絕與原生 executable 同用。原使用者瀏覽器載入逾時的確切原因未直接確認，不宣稱已找出。

C、D 槽資訊僅完成規劃，未實作；移除 Node 的分支未合併，安裝版仍包含 Node。
