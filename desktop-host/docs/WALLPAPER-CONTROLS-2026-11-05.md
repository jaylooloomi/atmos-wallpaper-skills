# 桌布停用與重新啟用（0.7.5）

管理頁上方浮動控制列提供三個常駐操作：

- **停用並恢復原桌布**：立即儲存宿主的 `placement.enabled=false`，由原生宿主移除所有 Atmos 桌布層。管理頁和設定保留。
- **重新啟用 Atmos**：使用保存的螢幕目標及配置重新掛載，與外觀草稿的「套用變更」分開。
- **重新確認狀態**：重新讀取宿主設定與實際掛載回報；等待中、未確認與操作失敗不顯示為已完成。

原本藏在「桌布與系統設定」裡的顯示器操作仍保留。上方快速操作一律沿用已保存的 target，不會意外套用顯示器下拉選單中尚未提交的選擇。獨立、重複與全景模式也沿用原配置，停用會移除其全部 Atmos 層。

停用是持久的宿主設定，沒有刪除素材、修改外觀 JSON 或更改 Windows 靜態桌布路徑；開機啟動偏好獨立保留。這不是退出應用程式，嵌入的管理服務仍在運作。若要停止整個 App，使用系統匣「退出並還原桌布」。停用後的重新啟用不會自動提交管理頁外觀草稿。
