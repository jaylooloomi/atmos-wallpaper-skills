# 資訊省電模式（0.7.8）

管理頁上方浮動列，以及「桌面元件 → 桌布與系統設定 → 效能與省電」，均可切換同一個「資訊省電模式」。開關立即儲存至獨立效能政策，不提交或取消外觀／資訊來源草稿。若效能設定本身有草稿，先明確儲存或取消，避免快速開關丟失 FPS 選擇。

## 行為

- 暫停背景雨、雪、雷光等 Canvas 繪製，隱藏殘留天氣層；背景場景靜態顯示。
- 背景動畫排程由 requestAnimationFrame 改為每秒一次的狀態檢查，避免 60Hz 空轉。僅控制背景迴圈，不攔截整頁或資訊更新所需的 requestAnimationFrame。
- 資訊卡片與日曆停用 backdrop blur／box shadow，場景內 CSS 動畫與 transition 暫停；保留文字內容更新及原色彩。
- 管理頁預覽同步簡化，避免桌布停止、預覽仍持續跑雨效。
- 時鐘、日曆、新聞、RSS、核心狀態同步與真實 renderer ACK 繼續；來源抓取間隔不變。
- 不改寫場景、天氣類型／強度、元件位置、素材、音訊、登入啟動或 Windows 電源計畫。關閉後沿用最新保存的原特效及一般 FPS／全螢幕／電池政策。
- 新安裝／舊設定缺欄位時預設關閉，保留原行為。此次實機測試會暫時切換並恢復原偏好，不擅自把使用者永久切到另一種模式。

這是減少 Atmos 背景工作量的模式，並非「零 GPU」或實際瓦特保證：資訊更新、文字繪製、WebView2 與 DWM 合成仍有成本，也沒有承諾釋放全部既有顯存。

## JSON 與相容性

`performance-settings.json` 的 `performance` 加入 `informationMode:boolean`，預設 false；原有 `fps`、`pauseFullscreen`、`pauseBattery` 保留。沿用 `--performance-command get|update` 及已認證管理角色 `/api/host/performance`，使用 requestId 與 expectedRevision。舊文件不會僅因讀取而改寫；舊客戶端更新未提供新欄位時，保留現有模式，不默默關閉。

原生 runtimePolicy 提供 `informationMode`、`paused`、`effectiveAnimationFps` 與 reason。模式開啟時有效背景 FPS 為 0，原本設定的 fps 保留以供恢復。這是繪製政策，不是量到的實際呈現 FPS。UI 區分已保存與等待宿主同步。

renderer ACK 可附帶受限的 `animation` 自述：informationMode、drawCount、scheduleCount。伺服器驗證欄位、型別與非負安全整數；舊 ACK 不必提供。計數不加入 desiredHash、投影或圖片 key，不導致每次回報重新載入背景。這些回報是 WebView 自述，不冒充 OS 可見性、GPU 或人眼驗證。

## 自動驗證

- 完整產品／核心驗證：488 項通過、5 項平台條件略過；原生 Rust 效能測試 4 項通過。
- 新測試涵蓋桌布與管理頁暫停／恢復、一秒背景排程、開關同步、偏好保留、草稿與 CAS 衝突，以及受限診斷欄位。
- 12 種尺寸、28 元件／主題狀態及三分頁；維持 1,008 次資訊範本檢查，另加 336 次省電狀態幾何與天氣層隱藏檢查。故意重疊負對照必須被拒絕。
- 安裝升級、來源／前端與原生設定比對：`../evidence/information-saving-upgrade-2026-11-05.json`。
- 真實安裝版一般／省電／一般短測：`../evidence/information-saving-installed-2026-11-05.json`。同一宿主、同一原工作負載，使用已認證管理 API；比較真正 WebView 背景繪製計數、資訊回報與 GPU 計數器，不偽造 ACK。效能 revision 因可逆測試增加，原偏好值與其他設定保留。
- 測試結束後獨立程序存活檢查：`../evidence/information-saving-handoff-2026-11-05.json`。

## 本機短測結果

同一安裝版宿主、原 rain／intensity 100 與管理頁開啟，每段規劃採樣 45 秒；包含收集器啟動與回報讀取的 renderer 計數觀察窗約 53 秒。沒有改動場景或來源，測試後恢復原效能偏好（資訊省電模式關閉）。

| 階段 | 最忙 GPU 引擎 median／p95 | 有效 GPU／採樣數 | 桌布背景繪製次數 | 管理預覽背景繪製次數 |
| --- | --- | --- | --- | --- |
| 一般（前） | 50.26%／50.70% | 15／16 | 1,567 | 1,395 |
| 資訊省電 | 2.95%／3.36% | 13／14 | 0 | 0 |
| 一般（後） | 49.36%／50.34% | 14／15 | 1,570 | 1,443 |

省電段兩個 renderer 的背景排程各約 0.98 次／秒，新聞資料可用、全目標 ACK 持續；回到一般模式後繪製恢復。有效 GPU 分母排除各段首筆暖機，完整統計保留於 JSON。這些是繪製呼叫與引擎活動，不是實際呈現 FPS、瓦特或可泛化的固定節省比例。

GPU 指標是歸屬程序在同一實體引擎內合計後的最忙引擎，不是整張 GPU 百分比，DWM 未完整歸因；短測可能受其他工作負載影響，不外推成兩小時、零洩漏、瓦特或續航改善。實際數值、覆蓋缺口及旗標以實測 JSON 為準；沒有有效計數器時保持未量測，不補零。
